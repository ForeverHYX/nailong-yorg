# 🐲 奶龙围城.io

YORG.io 玩法复刻版（表情包皮肤）：大地图供应链塔防，白天搞订单，夜晚守奶龙军团，无尽生存冲存活天数排行。

**🎮 在线玩：<https://foreverhyx.github.io/nailong-yorg/>**（也可双击 `index.html` 本地玩）

## 怎么玩（YORG.io 式）

- **🗺️ 大地图**：64×64 地图，拖动 / WASD 移动镜头，滚轮缩放（两档），左下小地图点击跳转。🍜外卖商家散布全图。
- **📦 供应链**（核心）：采集站建在商家上抽订单（0.9×等级/秒）→ 美团袋鼠驮回仓储（站点/仓库就近卸货）→ 🏭弹药厂烧订单换弹药（0.5订单/s → 1.0弹药/s）→ 袋鼠给塔补弹。商家订单耗尽会打烊，要持续外扩。仓库 +250 容量。
- **🌙 守夜**：奶龙军团从基地四周 17~23 格外的黑暗中压来，一路拆楼。保温墙拖时间，奶茶塔速射 / 冰奶昔减速 / 火锅溅射 / 麻辣电塔连锁。
- **👑 Boss**：每 5 夜「奶蛙之母」渡劫飞升形态降临，悬浮产蛙。
- **♾️ 无尽**：没有通关。死了按存活天数进本地 top5 排行（右上角实时显示）。
- **快捷键**：`1-8` 建造，`X` 出售（回收60%），`空格` 暂停，`⏩` 1x/2x/4x 变速，右键/Esc 取消。

## 文件

- `index.html` — 界面与样式
- `game.js` — 全部逻辑（角色优先加载 `assets/` 素材，失败回退矢量占位）

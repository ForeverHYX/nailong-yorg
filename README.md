# 🐲 奶龙围城 · 袋鼠外卖保卫战

YORG.io 玩法魔改版：白天搞钱搞后勤，夜晚奶龙军团来袭，撑过 15 夜即胜利。

**🎮 在线玩：<https://foreverhyx.github.io/nailong-yorg/>**（也可直接双击 `index.html` 本地玩，无需联网）

## 怎么玩

- **白天（50 秒）**：
  - 在 🍜 外卖商家上建【采集站】，美团袋鼠往返送餐赚金币；商家订单有限，送完歇业，记得扩张
  - 建塔防御：🧋奶茶塔（单体）/ 🥤冰奶昔塔（减速）/ 🍲火锅塔（溅射）/ ⚡麻辣电塔（连锁）
  - 塔的弹药由站点生产、袋鼠骑手配送——塔太多补给跟不上会哑火，可升级站点提升产能
  - 🧱保温墙便宜耐啃，是拖延奶龙的主力
  - 白天建筑自动缓慢修复；点击建筑可升级（最多 3 级）或出售（回收 60%）
- **夜晚**：奶龙（8 种随机动物皮肤：蛋形/企鹅/鼠/鸡/狗/马/兔/天使）、大笑奶蛙、暴暴龙从四面袭来；每 5 夜 Boss「奶蛙之母」（渡劫飞升形态）降临并无限产蛙
- **快捷键**：`1-6` 选建筑，`X` 出售模式，`右键/Esc` 取消，`空格` 暂停，顶栏可 2 倍速

## 文件

- `index.html` — 界面与样式
- `game.js` — 全部逻辑与渲染（角色优先加载 `assets/` 真实素材，加载失败自动回退内置矢量手绘）
- `assets/` — 角色素材（免抠 PNG）

## 调试接口（浏览器控制台）

`window.G`：`G.state` 游戏状态、`G.money(n)` 加钱、`G.place(x,y,type)` 免费建造、
`G.spawn(type,x,y)` 刷怪、`G.night()` 立即入夜、`G.clearNight()` / `G.endNight()`、`G.step(dt)` 单帧推进、`G.sprites()` 素材加载状态。
